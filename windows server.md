# Windows Server Administration Lab

هذا المستودع يوثق مهاراتي في إدارة بيئة Active Directory باستخدام Windows Server.

## المهارات التي أتقنتها:
* **Domain Controller Setup:** تثبيت وتكوين Windows Server كـ Domain Controller.
* **User & Group Management:** إنشاء حسابات المستخدمين (Users) وتوزيعهم في مجموعات (Groups) لضبط الصلاحيات.
* **Security Policies:** إدارة كلمات المرور (Password Policies) وتأمين حسابات المستخدمين.
* **Domain Joining:** ربط أجهزة الكمبيوتر (Clients) بنطاق الشركة (Domain).
* **Network Infrastructure:** تكوين الـ DNS Server وضمان الاتصال الصحيح بين السيرفر والأجهزة العميلة.

## الأدوات المستخدمة:
* Windows Server 2022 (أو النسخة التي استخدمتها).
* VMware Workstation / VirtualBox.
